SECAO 6 — ARQUITETURA E QUALIDADE
----------------------------------------------------------------------

  Padroes adotados:
  - DDD (Domain-Driven Design) com agregados Sale/SaleItem
  - CQRS via MediatR (Commands, Queries, Handlers)
  - External Identity Pattern (CustomerId+CustomerName, BranchId+BranchName)
  - Value Objects: Rating (Product), UserName, Address, Geolocation (User)
  - Repository Pattern com interfaces no Domain
  - AutoMapper para todos os mapeamentos de camadas
  - FluentValidation em todas as entradas
  - ValidationBehavior no pipeline MediatR

  Estrutura de camadas:
  - Domain     → Entities, Value Objects, Events, Repository interfaces
  - Application → CQRS Handlers, Validators, AutoMapper Profiles
  - ORM        → EF Core Config, Migrations, Repository implementations
  - WebApi     → Controllers, Request/Response models, Middleware
  - IoC        → Dependency injection registration

  Qualidade:
  - 82 testes unitarios (0 falhas)
  - Middleware de excecoes: ValidationException(400), KeyNotFoundException(404),
    UnauthorizedAccessException(401), InvalidOperationException(400),
    Exception (500 com log)
  - JsonStringEnumConverter: enums aceitos como string ("Active", "Admin")
  - Respostas padronizadas: ApiResponseWithData<T> e formato de erro { type, error, detail }
